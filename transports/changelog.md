## ✨ Upstream

- fix: **Anthropic web search on chat completions stays server-side.** The streamed `server_tool_use` input (`input_json_delta`) no longer leaves as an orphan `tool_calls` delta with no id or name, which OpenAI clients treated as a real tool call. Text-block `web_search_result_location` citations, which were dropped, now become `annotations[].url_citation` on the message and on the cited block's stream delta, spanning the block's bytes in the content string, the shape Gemini grounding uses. Hosts that run the Anthropic chat converter get it: Anthropic, Vertex, Azure, and Bedrock on its InvokeModel path; Bedrock web search alone goes through Converse, which does not carry the tool for Claude (upstream 1d3846bb1, #7656)
- fix: the unscoped `GET /v1/models` aggregate bounds each list-models page with the 5s deadline instead of a provider's whole page walk, so a large catalog is no longer cut off after its first 1,000 models with no `next_page_token`. An unreachable provider is still bounded to one window; a reachable provider's walk is bounded by the 20-page limit and, in this fork, a 60s walk deadline (upstream aa098c568, #8767)
- fix: a Bedrock chat tool message whose content is a single text block renders like the equivalent string, so a client that sends the last tool result as a block (to carry `cache_control`) and earlier ones as strings keeps the cached prefix stable across turns. The block's `cache_control` still becomes the `cachePoint` after the `toolResult` (upstream 22ddcbd56, #8801/#8803)
- feat(ui): the Complexity Router's decision-model picker is the shared `DecisionModelSelector`, and the decision-provider rules live in `decisionModelProviders.ts` for Prompt Guardrails' decision judge too; the Complexity Router behaves as before (upstream 35899b385, #8487)
- chore(deps): dependency updates for the UI (`vite` 8.1.6, `follow-redirects`), the TypeScript integration tests (`vite` 6.4.4) and the Python integration tests (`aiohttp`, `yarl`, `pillow`, `certifi`) (upstream 369d68434, #8777)
- ci: StepSecurity action updates: `step-security/setup-helm` and `step-security/setup-gcloud` replace `azure/setup-helm` and `google-github-actions/setup-gcloud`, the core-tests authorize job hardens its runner in audit mode, and Dependabot lists 17 more directories (upstream bbc4767f7, #7045)
