- **BREAKING** (TXE-7705): on Vertex and Bedrock, a virtual key with no `allowed_storage_prefixes` may no longer name storage (`gs://`/`s3://` inputs and their https forms, output locations, batch input files and output folders, file operations' `storage_config`), and one with no `allowed_pubsub_topics` may no longer name a Pub/Sub topic: the request is refused with 400 `caller_unsupported_parameter` (`error.param` `storage_location` or `pubsub_topic`). A key with a list works as before. Give each key that names storage or topics on those providers a list.
