## Changelog

Prerelease of the txehq fork for transport v2.4.0-sync.3; the stable chart stays 2.1.51 until a stable version supersedes it. Install this one with `helm install --devel` or `--version 2.1.52-sync.3`.

- `appVersion` is now `2.4.0-sync.3`, so an empty `image.tag` selects `v2.4.0-sync.3`. That transport keeps Anthropic web search server-side on chat completions and returns its citations as `url_citation` annotations, bounds each `ListAllModels` page instead of the whole walk, and renders a one-text-block Bedrock tool result like its string form. No values, templates or schema change.
