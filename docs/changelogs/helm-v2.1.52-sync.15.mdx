## Changelog

Prerelease of the txehq fork for transport v2.4.0-sync.15; the stable chart stays 2.1.51 until a stable version supersedes it. Install this one with `helm install --devel` or `--version 2.1.52-sync.15`.

- The chart's templates and values are unchanged from 2.1.52-sync.14, so a chart that renders today renders the same `config.json`. `values.schema.json` adds the model families `gemma`, `llama`, `imagen`, `veo` and `mai-image` to a custom provider's `model_family` enum.
- `appVersion` is now `2.4.0-sync.15`, so an empty `image.tag` selects `v2.4.0-sync.15`. For a virtual key with a dollar budget, that transport refuses a model the price book cannot price (TXE-7957, TXE-8016), a queued or webhook-delivered answer nothing will charge (TXE-7963, TXE-8013), and concurrent requests on a price row until an answer on it is priced (TXE-7977). It reads a forwarded body by its declared Content-Type and refuses an ambiguous or repeated-member body (TXE-8012, TXE-7994), and refuses request fields a vendor would drop or change (TXE-7063, TXE-7954, TXE-8011). It adds no migration. Read the transport changelog's breaking changes before upgrading.
