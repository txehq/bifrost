## Changelog

Prerelease of the txehq fork for transport v2.4.0-sync.4; the stable chart stays 2.1.51 until a stable version supersedes it. Install this one with `helm install --devel` or `--version 2.1.52-sync.4`.

- `appVersion` is now `2.4.0-sync.4`, so an empty `image.tag` selects `v2.4.0-sync.4`. That transport serves MiniMax through upstream's provider: chat with reasoning returned in `reasoning_content`, Responses, image generation, async video generation, text-to-speech and speech-to-text, with MiniMax's `base_resp` errors mapped to HTTP status codes. The fork's MiniMax text completions are kept. No values, templates or schema change.
