## Changelog

Prerelease of the txehq fork for transport v2.4.0-sync.5; the stable chart stays 2.1.51 until a stable version supersedes it. Install this one with `helm install --devel` or `--version 2.1.52-sync.5`.

- `appVersion` is now `2.4.0-sync.5`, so an empty `image.tag` selects `v2.4.0-sync.5`. That transport adds upstream's BytePlus ModelArk provider (`byteplus`): chat with `reasoning_effort` mapped onto Ark's `thinking` switch, the native Responses API, multimodal embeddings, Seedream image generation and editing (streamed or not), and Seedance video generation with retrieve, list, download and delete. The fork's `modelark` and `volcengine` providers are unchanged. No values, templates or schema change.
